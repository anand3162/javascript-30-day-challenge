# Day 12 – DOM Playground

An interactive page where each button demonstrates a different DOM manipulation technique.

## Features

- **Change Text** – updates the heading text
- **Toggle Highlight** – toggles a `highlight` CSS class on the heading
- **Add List Item** – creates and appends a new list item
- **Item Counter** – tracks how many items have been added
- **Clear List** – removes all items and resets the counter

## Concepts Practiced

- Selecting elements with `querySelector()`
- Handling events with `addEventListener()`
- Updating content with `textContent` and `innerHTML`
- Managing CSS classes with `classList.toggle()`
- Creating and inserting elements with `createElement()` and `appendChild()`
- Tracking state with a `let` variable

## How to Run

Open `index.html` with the Live Server extension in VS Code, or open it directly in a browser.
