# Day 05 – Multiplication Table Generator

## Task
Print the multiplication table (1 to 12) for a given number using a for loop and template literals.
Bonus: use nested loops to print the tables for 1 through 5, and use continue to print only odd results.

## What I learned
- A for loop has three parts: start, condition, and update
- In a nested loop, the inner loop runs completely for every step of the outer loop
- continue skips the rest of the current loop step and moves on to the next one
- Template literals can do math inside ${}, like ${i * n}

## How to run
node script.js
